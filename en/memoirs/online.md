Memory or reminiscence pieces published on blogs, WeChat public accounts,
forums, and similar platforms. The author may be a reporter, engineer,
administrator, or affected resident — this category isn't split further by
author type. Online content like this is especially prone to disappearing
(link rot, deleted accounts, content removal), so every entry records an
archived copy alongside the original URL. This section holds source
information and a brief summary only, not reproduced text — see
<a href="{{ '/en/methodology/' | relative_url }}">Sources &amp; Methodology</a>.

## Entry format

| Field | Description |
|---|---|
| Title | Article title |
| Author | Author's name or online handle (if known), and their relationship to the event |
| Platform | Where it was published (personal blog, WeChat account, forum, etc.) |
| Original URL | Link to the original article |
| Archived copy | Link to a web-archive snapshot, or a note that a private local snapshot exists; entries that couldn't be archived should say why |
| Publish date | The article's publish date, if determinable |
| Accessed/archived date | The date this project consulted or archived the content |
| Summary | A brief, non-verbatim description of the content relevant to this project |
| Rights status | Typically "cited only," or a short fair-use quotation of a specific fact where needed (see Sources &amp; Methodology); this site does not reproduce the full text or extended passages |

## WeChat entries: citation format and archiving notes

WeChat public-account (公众号) articles are the least stable source type in
this category — they can disappear at any time due to platform moderation,
account bans, or the author's own deletion, and they aren't indexed by
search engines, which makes independent verification harder. When adding
one:

- **Record both the account name and account ID**, not just the display
  name — display names can be changed after the fact. Screenshot the
  account's info page as supporting evidence (the ID itself can eventually
  be recycled after an account is deleted, so treat it as corroborating,
  not sole, evidence).
- **Author**: use the individual's name if the article is signed; if not,
  treat the account itself as the responsible party.
- **Publish date** is the date shown on the article; **accessed/archived
  date** is when this project actually consulted or archived it. Keep
  these separate, since WeChat articles can be silently edited after
  publication — the archive snapshot is the only proof of the exact
  version being cited.
- **Archiving**: try archive.today first (it handles WeChat pages more
  reliably than the Wayback Machine, which is also worth trying as a
  backup). If both fail, fall back to WeChat's own share/export function or
  a full-page screenshot/print-to-PDF as a manual archive, and note in the
  entry "automated archiving failed, manual screenshot archive used."
- **Reposts**: if the original was already deleted and it's only findable
  via someone else's repost (e.g., a screenshot shared on Weibo or Zhihu),
  say so explicitly ("secondhand repost, not archived from the original")
  and lower the reliability assessment accordingly.

Recommended citation format (adapting the GB/T 7714 convention for online
sources):

> Author (or account name). "Article Title." WeChat account: Account Name
> (Account ID), published [date] [accessed date]. Original URL. Archived
> at: [archive link].

## Notes

- Online content is generally harder to verify for authenticity and
  authorship than formal publications; entries are assessed against the
  verification principles in Sources &amp; Methodology, and uncertain
  reliability is noted in the summary.
- Content involving living individuals also follows the interview-ethics
  and anonymization principles described there.
- This category does not include posts that only argue over casualty
  numbers without offering first-hand memory content — see the Rights
  &amp; Reuse section of Sources &amp; Methodology for how that material is
  handled instead.
