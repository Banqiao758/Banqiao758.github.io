发布于博客、公众号、论坛等网络平台的回忆或追述文章，作者身份可能属于记者、工程
技术人员、行政管理人员或受灾群众中的任何一类，此处不再按身份细分。此类内容尤其
容易因链接失效、账号注销或内容被删除而消失，因此每条目除原始网址外，还会记录一
份存档链接（如网页存档服务的快照）。本节仅收录出处信息与简要提要，不转载原文，
详见<a href="{{ '/methodology/' | relative_url }}">《史料与方法》</a>。

## 条目格式

| 字段 | 说明 |
|---|---|
| 标题 | 文章标题 |
| 作者 | 作者姓名或网名（如可考），及其与事件的关系 |
| 平台 | 发布平台（如个人博客、微信公众号、论坛等） |
| 原始网址 | 文章原始链接 |
| 存档链接 | 网页存档服务快照链接，或注明"已本地留存快照，未公开"；无法存档的条目应说明原因 |
| 发布日期 | 文章发布日期（如可考） |
| 访问/存档日期 | 本项目查阅或存档该内容的日期 |
| 内容提要 | 与本课题相关内容的简要、非逐字介绍 |
| 权利状态 | 通常为"仅注明出处"，或就具体史实作简短合理引用（详见《史料与方法》）；本站不转载全文或大段原文 |

## 微信公众号条目：引用格式与存档要点

微信公众号文章是本分类中最不稳定的来源类型——可能因平台审核、账号被封或作者自
行删除而随时消失，且不被搜索引擎收录，难以独立核实。收录此类条目时：

- **账号名称与账号ID均需记录**，不能只记公众号显示名称——显示名称可事后更改，
  应同时截图保存账号信息页作为佐证（账号ID在账号被注销后也可能被回收再用，仅作
  参考，不能单独作为唯一凭证）。
- **作者**：如署名个人，按个人记录；如未署名，以公众号本身作为责任主体。
- **发布日期**为文章显示日期，**访问/存档日期**为本项目实际查阅或存档的日期，
  二者需分开记录，因公众号文章存在事后静默修改的可能，存档快照是所引用版本的
  唯一凭证。
- **存档**：优先尝试 archive.today（对微信页面的抓取成功率通常高于 Wayback
  Machine），同时尝试 Wayback Machine 作为备份；两者均失败时，采用微信自带的
  分享/导出功能或整页截图/打印为PDF作为人工存档，并在备注中注明"自动存档失败，
  采用人工截图存档"。
- **转发件**：若仅能通过他人转发（如微博、知乎上的截图转发）找到已被删除的原
  文，须在条目中明确注明为"转发件，非原文直接存档"，并适当降低可信度评估。

推荐引用格式（参照GB/T 7714网络文献著录规则）：

> 作者（或公众号名称）.《篇名》[EB/OL]. 公众号：账号名称（账号ID），发布日期
> [引用日期]. 原始网址. 存档：存档链接.

## 说明

- 网络内容的真实性、作者身份核实难度通常高于正式出版物，收录前须结合《史料与
  方法》的核实原则加以判断，可信度不明的内容会在提要中注明。
- 涉及仍在世个人的内容，另参照《史料与方法》中的访谈伦理与匿名化原则处理。
- 本分类不收录仅涉及伤亡数字争议、缺乏第一手回忆内容的网络帖文；此类材料的处
  理方式见《史料与方法》"版权与再利用"一节。
